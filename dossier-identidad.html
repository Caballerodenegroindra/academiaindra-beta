Este documento fija el lenguaje visual de Academia Indrhack antes de construir una sola página nueva: cómo se ven el color, la tipografía, los botones y las tarjetas. Nada de esto todavía funciona — es la base sobre la que se arma el resto, expediente por expediente.

I.

Paleta

Color

Marino casi negro de fondo, como el sello. Un único acento cálido —latón, no dorado brillante— para lo importante. El acero del logo queda para lo secundario. Verde y rojo apagados hacen de sello de "aprobado" y "restringido", nunca de decoración.

Tipografía

Type

Cuatro roles, cada uno con un trabajo: Cinzel solo para el titular grande (el grabado del sello), Source Serif 4 para subtítulos con voz de informe, Public Sans para todo el texto de lectura —es la misma familia que usan los sitios oficiales de EE. UU.— y JetBrains Mono para expedientes, etiquetas y datos.

VI.

Campo de formulario

Componentes

Etiquetas en mayúscula, foco en latón. Ejemplo: solicitud de acceso a la comunidad.

Acta de aprobación

  • Fondo marino casi negro, nunca blanco puro.
  • Un único acento cálido —latón #B08D4F—, cero dorado brillante ni pill buttons.
  • Cinzel solo en titulares grandes; el resto, Source Serif 4 / Public Sans / JetBrains Mono.
  • Radios chicos (3–5px) y bordes dobles en los marcos principales, como un sello grabado.
