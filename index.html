Tecnología

Cómo está hecho

Infraestructura propia, pensada para muchos usuarios a la vez y para no caerse.

// arquitectura de Indra Bot (resumen)
stack     = ["Node.js", "Baileys", "SQLite / Postgres", "Caddy"]
instancias = 34   // un proceso por número, aislado
red       = "salidas propias por instancia"
ia        = ["LLM para charla", "visión: filtro +18"]
media     = ["stickers", "video", "tarjetas HD"]
deploy    = "recarga en caliente, sin cortar"
monitoreo = "latencia por comando, alertas 24/7"
